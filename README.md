## Overview

This repository contains the reproducibility materials associated with the
MLP Gateway study for robust reconstruction of questionnaire-derived
psychometric representations under structured response perturbations.

The repository contains the final preprint, the IPIP-NEO-120 and IPIP-NEO-300
computational notebooks, supporting figures, reference metadata, and
reproducibility documentation.
